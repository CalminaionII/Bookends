# Bookends

A Vintage Story mod: carve a pair of bookends in wood, then press them into a clay mold and cast them in metal. Designs and metals are JSON, so other mods can add their own with one file.

- Mod page: https://mods.vintagestory.at/bookends
- Guide for modders: [MODDERS.md](MODDERS.md)
